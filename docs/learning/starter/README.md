# 장비 없이 해보는 첫 실습

[학습 안내](../README.md) · [제어 안내](../tracks/control.md) · [웹 안내](../tracks/web.md)

이 폴더 전체를 받은 뒤 VS Code에서 이 폴더를 열고 Terminal → New Terminal을 선택한다. 저장소 전체를 열었다면 루트에서 `cd docs/learning/starter`를 먼저 실행한다. Python이 없으면 담당자와 설치부터 진행한다.

## PD 출력 부호

```powershell
python first_control_exercise.py
```

+10도에 음수, -10도에 양수 출력이 나온다. 끝에 `PASS`가 나온다. 파일의 `kp`, `kd`는 교육용이며 출력은 정규화한 요청이다. PWM·추력·실제 서보 각도가 아니고 기체 운동을 계산하는 시뮬레이터도 아니다.

## 3D 모형

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8000/>을 연다. HTML 파일을 더블클릭하는 방식은 ES module 로딩 오류가 날 수 있다. 8000 포트를 다른 프로그램이 사용하면 8001로 바꾸고 주소도 맞춘다.

슬라이더로 모형을 움직이고 초기화한다. 합성 반복 회전을 켰다가 끈다. `index.html`의 `fanColor`를 `0x2778a9`에서 `0x2d9c66`으로 바꾼 뒤 저장·새로고침한다. 팬 색이 바뀌는지 확인한다. 실습 후 서버 터미널에서 Ctrl+C로 종료한다.

Three.js 0.180.0 모듈과 MIT 라이선스를 `vendor/`에 동봉했다. 첫 화면은 CDN과 npm 설치를 요구하지 않는다. Python과 WebGL 지원 브라우저는 필요하다. 이 모형은 프리미티브로 만든 연습 형상이며 CAD 정본·IMU·RL·물리 연산과 연결하지 않았다. 화면은 Y-up, 슬라이더는 화면 Z축 회전이다. 실제 기체의 roll로 그대로 해석하지 않는다.

## CSV 읽기

`sample-synthetic.csv`는 시간 0–1000ms의 합성 데이터 5행이다. 실제 계측·비행 로그가 아니다. `phi/theta/psi`는 라디안이며 phi=0.174532925는 약 10도다. `source=SYNTHETIC`으로 출처를 구분한다. `mode=MANUAL`은 연습용 표기다. 없는 서보·배터리 측정치를 만들어 넣지 않았다.

현재 3D 화면은 CSV를 읽지 않는다. 다음 과제에서 CSV 파서·차트·좌표계 변환을 연결한다. 최종 텔레메트리 계약은 [웹 설계 §4](../../design/02-web-dashboard-design.md)를 따른다.

## 확인한 범위

PD 부호·감쇠·출력 제한, CSV의 5행·수치, JavaScript 구문, 로컬 HTTP 파일 제공을 검사했다. 브라우저에서 3D 모형 렌더링, +25도 슬라이더 반영, 0도 초기화, 합성 반복 회전을 확인했다. 팬 색 수정 실습과 각 부원 PC의 실행은 별도 확인한다. 테스트 중 WebGL 컨텍스트가 일시적으로 끊겼다가 복구된 로그가 있었다. 보드 업로드·센서 수신 검증을 대신하지 않는다.
