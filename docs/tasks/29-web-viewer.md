# #29 CSV 재생 3D 뷰어 (김민지)

## 지금 상태

- 시뮬레이션은 에피소드를 웹 CSV 계약 형식으로 저장한다(`sim/sim_stage1/export_episode.py`, #23).
- 웹 앱 폴더가 없었다. 이번에 `web/`에 **실행되는 뼈대**를 만들었다. 설계 문서(02 §7)대로 Vite + 바닐라 JS + Three.js + PapaParse다.
- 이 위에서 판정 기준을 확인하고 남은 기능을 붙이는 게 이번 일이다.

## 용어

- **Vite:** 웹 코드를 저장하면 브라우저가 바로 새로 고쳐지는 개발 서버이자 빌드 도구.
- **쿼터니언(qw, qx, qy, qz):** 3D 회전을 숫자 4개로 나타내는 방법. 오일러각과 달리 90° 근처에서 망가지지 않는다.
- **Y-up:** Three.js는 위쪽이 +Y다. 우리 기체는 위쪽이 +Z다. 그래서 변환 함수가 필요하다.
- **헤더로 컬럼 찾기:** CSV 첫 줄의 이름으로 칸을 찾는 것. 컬럼 순서가 바뀌어도 안 깨진다.

2026-10-16 확인: `npm run build` 통과. 브라우저에서 축 확인용 CSV를 열어 150번째 행이 `theta+20`, Pitch 20.0°로 표시되는 것을 봤다. 변환 함수를 숫자로 검증한 결과 theta +20°에서 FWD 끝의 높이가 −0.342(아래로), phi +20°에서 LEFT 끝이 +0.342(위로), psi +20°에서 FWD가 LEFT 쪽으로(위에서 반시계) 움직였다.

## 첫 30분

Node.js LTS가 설치돼 있어야 한다.

```bash
cd web
npm install
npm run dev
```

터미널에 나온 주소(보통 `http://localhost:5173`)를 연다. 정상 결과: 회색 호퍼와 빨간 FWD 화살표가 보이고, "예제 선택"에서 시뮬레이션 PD를 고르고 재생하면 기체가 5초 동안 흔들리다 수평으로 돌아온다.
