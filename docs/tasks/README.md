# 과제 착수 초안

PRD 이슈(#26-#29)는 "무엇을, 어디까지" 하는지 정한다. 이 폴더는 그 일을 **어디서부터 손대면 되는지** 보여 주는 초안이다. 담당자가 빈 화면에서 시작하지 않도록 실행되는 뼈대 코드, 채우기만 하면 되는 기록 양식, 지금 돌려 본 결과를 미리 넣어 두었다.

초안은 출발점이다. 숫자와 판단은 담당자가 다시 확인하고, 틀린 곳은 고친 뒤 PR에 적는다. 초안을 만든 사람이 실물로 확인하지 못한 것은 각 문서의 "확인 못 한 것"에 적었다.

## 쓰는 법

1. PRD 이슈를 먼저 읽고 "이해 먼저" 세 가지를 댓글로 쓴다.
2. 자기 착수 문서의 **첫 30분**을 그대로 따라 한다. 정상 결과가 나오면 환경은 준비된 것이다.
3. **이어서 할 일**을 작은 PR로 나눠 진행한다. 순서는 `AGENTS.md` §작업 순서(이슈 → `python ship.py wt <이슈 번호>` → 검사 → PR)을 따른다. PRD 번호로는 브랜치를 만들지 않는다. 한 PRD를 여러 명이 맡으면 브랜치 이름이 겹치기 때문이다. PRD 아래에 사람별 작업 이슈(`.github/ISSUE_TEMPLATE/task.yml`, `gh issue create --parent <PRD 번호>`)를 만들고 그 번호로 브랜치를 만든다.
4. 진행 보고는 PRD 이슈에 세 줄로 남긴다.

AI에게는 이렇게 묻는다. `(이름)`과 `(문서)`만 바꾼다.

```
나는 COSMOS의 (이름)이야. docs/tasks/(문서)와 거기 연결된 PRD 이슈를 직접 열어 읽고,
1) 이 초안이 이미 해 둔 것과 내가 해야 할 것을 나눠서 설명하고
2) 첫 30분 단계를 나와 같이 실행해줘. 명령마다 무엇을 하는지 한 줄로 알려줘.
결과가 문서의 정상 결과와 다르면 멈추고 차이를 설명해줘.
```
