# #28 DShot 실물 시험과 CSV 계약 대조 (권재후, 김시우와 2인 1조)

## 지금 상태

- `firmware/cosmos/throttle_serial`(DShot 벤치 펌웨어)은 ESC 없이 Teensy에서만 확인했다(#19). 실제 ESC가 신호를 받아 도는지는 아무도 보지 않았다.
- 안전 기능: `arm` 전에는 숫자를 거부, 상한 DShot 600(27.6 %), 올릴 때 초당 20 %씩 천천히, 3초 동안 명령이 없으면 정지, 빈 줄 Enter = 비상정지.
- **안전 조건이 먼저다.** EDF 팬(로터)을 떼거나 추력 스탠드에 볼트로 고정한 상태, 킬스위치에 손, 부장 입회. 지도교사 서명 확인 전에는 EDF에 배터리 전원을 넣지 않는다(`AGENTS.md` 안전 원칙).

## 용어

- **ESC:** 배터리 전기를 모터가 쓰는 3상 전기로 바꾸는 속도 조절기.
- **DShot:** Teensy가 ESC에 스로틀 값을 디지털 숫자로 보내는 방식. 48~2047이 스로틀, 0은 정지.
- **arm:** "이제부터 돌려도 된다"는 허가. 실수로 모터가 도는 걸 막는다.
- **워치독:** 정해진 시간 동안 신호가 없으면 스스로 멈추는 장치.

## 첫 30분 (전원 없이 할 수 있는 것)

1. 펌웨어를 Teensy에만 올리고(ESC 연결 없이) 3·4·5·6·7번을 시리얼 모니터로 먼저 해 본다. 모터가 없어도 메시지와 `D,` 상태 줄은 똑같이 나온다.
   ```bash
   cd firmware/cosmos/throttle_serial; pio run -t upload
   pio device monitor --filter time --filter log2file
   ```
2. 정상 결과: 4번에서 `D,...,ARMED,5.0,x.x,yyy` 줄의 마지막 값이 0에서 올라가 약 0.25초(5 % ÷ 초당 20 %) 뒤 148에서 멈춘다. 로그는 `logs/device-monitor-*.log`에 남는다.
3. 이 연습 로그를 실물 시험 전 기준으로 `data/`에 남겨 둔다(예: `data/20261017-DSHOT-dry-01.log`).

## 펌웨어 출력 ↔ CSV 계약 대조표 (초안)

[웹 CSV 계약](../design/02-web-dashboard-design.md) §4 컬럼마다 지금 펌웨어가 무엇을 내는지 정리했다. 2026-10-16 코드를 읽고 쓴 초안이라 **"확인" 칸은 비워 두었다.** 실제 출력과 비교해서 채운다.

| 계약 컬럼 | 단위 | `imu_test_i2c` 지금 출력 | `throttle_serial` 지금 출력 | 판정 초안 | 확인 |
|---|---|---|---|---|---|
| `t_ms` | ms | 없음 | `D,` 줄 2번째 칸 `millis()` | throttle: 있음 / imu: 없음 | |
| `source` | 문자열 | 없음 | 없음 | 없음 (실물은 `REAL`로 정할지 결정) | |
| `mode` | PID/RL/MANUAL | 없음 | `state`(DISARMED/ARMED)는 다른 개념 | 없음 | |
| `phi`, `theta`, `psi` | rad | `Roll:`, `Pitch:`, `Yaw:` **도(deg)**, 탭 구분 | 없음 | 이름·단위 다름 | |
| `qw..qz` | - | 없음 (라이브러리 `getQuatReal()` 등은 있음) | 없음 | 없음 | |
| `wx..wz` | rad/s | 없음 (`enableGyro` 필요) | 없음 | 없음 | |
| `servo1..4` | µs 또는 −1~1 | 없음 | 없음 | 없음 (통합 펌웨어) | |
| `throttle` | 0~1 | 없음 | `output_pct` **0~100 %** | 단위 다름 (/100) | |
| `batt_v` | V | 없음 | 없음 | 없음 | |
| `rpm` | rpm | 없음 | 없음 (양방향 DShot 미사용) | 없음 | |

정리: 통합 펌웨어는 한 줄에 위 컬럼을 쉼표로 찍어야 한다. 이번 일은 **표만** 만들고 고치지 않는다(PRD #28 5절).
