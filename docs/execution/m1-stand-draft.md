# 구속 스탠드(M1) 설계 초안과 부품 목록 (#256, 초안)

**상태: 초안이다.** AI가 2026-11-12에 문서만 읽고 썼다. 실물과 CAD를 보지 않았고 부장(`MINBBBB1201`)의 검토 전이다. 아래 "제안"은 모두 결정이 아니다.

**결론(제안):** M1은 "기체를 한 점에 묶고, 롤·피치·요는 자유롭게 두고, 수직 이동은 짧은 거리만 허용하는" 장치여야 한다. 이유는 §2의 계산이다. 가장 큰 미결정은 수직 이동을 어떻게 허용하느냐다. 문서에 답이 없어서 §4에 선택지로 남겼다.

## 1. 문서에 적힌 것

확인한 사실(출처는 괄호):

- TC-0, 1, 2.5, 3, 4, 5는 모두 M1에서 한다([마스터 설계](../design/00-hopper-master-design.md) §11). 제작 순서 12번은 "M1 삼각대 마운트 준비, 킬 2중 확인"이다(§10).
- 구속 스탠드는 "카메라 삼각대/모노포드 + 저마찰 자유회전 조인트(십자축 만능조인트+스러스트 베어링)"이고, 사진용 볼헤드는 마찰로 잠겨서 쓰지 않는다(마스터 설계 L9, [BOM](../design/BOM-revC-teensy.md) F).
- BOM의 구속 스탠드 부품은 삼각대 또는 모노포드(F1), 십자축 조인트와 스러스트 베어링(F2), Ø8 스틸 연마봉 2×1 m(F3), Ø8 PTFE 부싱 4개(F4), 번지코드·카라비너·로프(F5), 방호판 또는 그물(F6)이다.
- 기체에는 상단 베일(Ø3 스틸봉, 손잡이이면서 M3 텐서 걸이)과 언더슬렁 M6 결합구가 있다([`general-arrangement.svg`](../design/general-arrangement.svg), `cad/hopper_params.scad`의 `bail_*`). 이 그림은 기둥을 200 mm로 그렸고 현재 CAD는 212 mm다.
- `cad/`에 M1 설계 파일은 없다. 구매 대장은 F1-F4를 "시험대 설계 후"로 둔다(`hopper-procurement-20261108.csv`).

아직 확인하지 못한 것:

- 상단 베일, 텐서, 언더슬렁 결합구, 삼각대 조인트가 서로 어떻게 연결되는지. 문서에 그림 설명은 있지만 조립 순서가 없다.
- F1-F6 중 실제로 있는 것(#242 대조 결과가 필요하다).
- 보유 PVC 파이프의 치수(#241).

## 2. 요구 조건과 계산

추정 입력(확인 필요): 기체 질량 0.735 kg(`params.yaml` 임시값)에서 0.93 kg(#219의 슬라이서 시나리오), EDF 사양 추력 1.3-1.46 kgf.

| 항목 | 계산 | 결과 |
|---|---|---|
| 최대 순양력(추력 - 무게) | 1.3 - 0.93 = 0.37 kgf, 1.46 - 0.735 = 0.725 kgf | 약 0.37-0.73 kgf (3.6-7.1 N) |
| 고정 하중(안전계수 3, 제안값) | 0.725 × 3 | 약 2.2 kgf 이상에서도 스탠드가 들리지 않아야 한다 |

**의미:** 추력이 무게보다 크다. 회전만 허용하는 조인트에 기체를 달면 스로틀을 올릴 때 기체가 위로 올라간다. 그래서 수직 이동을 허용하되 범위를 끊어 주는 장치가 필요하다고 본다(추론).

| 요구 | 내용 | 근거 |
|---|---|---|
| R1 롤, 피치 자유 | 조인트가 기체 무게중심 근처에 있어야 한다 | TC-3, TC-5는 자세 복원을 본다 |
| R2 요 자유 | 스러스트 베어링으로 요 회전을 허용 | TC-1이 요(4캔트) 부호를 본다 |
| R3 좌우 병진 구속 | 기체가 옆으로 흘러가지 않는다 | 구속 시험의 정의 |
| R4 수직 이동 제한 | 범위를 끊고 충격을 흡수한다 | 위 계산 |
| R5 마찰 | 조인트 마찰 토크가 베인으로 만드는 토크보다 충분히 작아야 한다 | 베인 토크는 TC-2(#263)가 잰다. 아직 값이 없다 |
| R6 방호 | 배기 축선 밖 위치, 방호판, 킬 경로 | `AGENTS.md` §안전 원칙 |

## 3. 제안하는 구성

```
        삼각대 또는 PVC 기둥 (F1)
              |
        Ø8 가이드 로드 2개 (F3) + PTFE 부싱 (F4)   <- 수직으로 미끄러짐
              |
        번지코드 (F5)  <- 수직 이동 끝에서 충격 흡수
              |
        십자축 조인트 + 스러스트 베어링 (F2)       <- 롤, 피치, 요
              |
        기체 (언더슬렁 M6 또는 상단 베일에 연결)
        방호판 (F6) 으로 둘러싼다
```

이 그림은 개념이다. 치수와 연결 부위는 정하지 않았다.

## 4. 부장이 정할 것

1. **수직 이동을 어떻게 허용할지.** (a) 가이드 로드와 부싱으로 미끄러지게 하고 번지로 받는다(위 구성). (b) 번지코드 하나로 매달아 탄성에 맡긴다. 부품이 적은 쪽은 (b)이고 구속이 확실한 쪽은 (a)라고 본다. (b)의 진동 특성은 확인하지 못했다.
2. **조인트를 기체의 어디에 연결할지.** 언더슬렁 M6와 상단 베일 중 어느 쪽이 무게중심에 가까운지는 CAD로 확인해야 한다(#252, #261의 CG 실측이 먼저다).
3. **요를 자유롭게 둘지.** TC-1은 요 부호를 보므로 자유가 필요하다고 본다. 요 권한이 약해서 마찰이 문제가 될 수 있다(마스터 설계 리스크 표).
