# TC-0 진동 한계 X와 측정 방법 (#253, 제안)

**상태: 제안이다.** AI가 2026-11-12에 썼고 부장(`MINBBBB1201`)의 승인 전이다. 숫자는 아직 정하지 않았다.

**결론(제안):** 지금은 X에 숫자를 넣지 않는다. 측정 방법과 X를 정하는 규칙을 먼저 정하고, 구속 시험에서 처음 얻은 값으로 X를 정한다. 첫 측정은 합격·불합격을 내지 않고 기록만 한다.

## 1. 지금 알려진 것

확인한 사실:

- 마스터 설계 §11의 TC-0 합격 기준은 "20-60 % 스로틀에서 진동 RMS < X, 이상음/열 없음, EDF 마운트 유격 0"이다. X의 숫자와 측정 방법이 적혀 있지 않다([`00-hopper-master-design.md`](../design/00-hopper-master-design.md) §11).
- 지금 IMU 스케치 `imu_test_i2c`는 회전 벡터(자세)만 읽고 보고 주기가 50 ms다. 코드는 `imu.enableRotationVector(50)`이다. 가속도와 각속도는 읽지 않는다(`firmware/cosmos/imu_test_i2c/src/main.cpp`).
- BNO080 라이브러리에는 `enableAccelerometer`, `enableLinearAccelerometer`, `enableGyro`가 있다(`firmware/cosmos/imu_test_i2c/src/BNO080.h` 155-157줄). 쓰는 스케치가 아직 없다.
- EDF는 3500KV급 4S 제품으로 샀다([`procurement-review.md`](procurement-review.md) A1).

추론(근거와 함께):

- 보고 주기가 50 ms이면 샘플 주파수가 20 Hz여서 10 Hz까지만 본다. 4S 공칭 전압 14.8 V에 3500KV를 곱한 무부하 이론 회전수는 약 51,800 rpm, 즉 약 860 Hz다. 실제 회전수는 이보다 낮지만 수십 Hz는 훨씬 넘을 것으로 보인다. 그래서 현재 방식의 "진동 RMS"는 회전자 진동이 아니라 기체와 스탠드의 느린 흔들림만 담는다.
- 제어기가 실제로 받는 잡음이 문제이므로, 측정 대상은 제어에 쓰는 IMU의 값이어야 한다고 본다.

아직 확인하지 못한 것:

- BNO085가 가속도와 각속도를 최대 몇 Hz로 보고하는지(데이터시트 확인 필요).
- 실제 EDF의 무부하·부하 회전수(#119가 잰다).
- 기체와 스탠드의 공진 주파수.
- 비슷한 시험의 기준값. 이 저장소에는 없고 외부 자료도 찾아보지 않았다.

## 2. 측정 방법 (제안)

| 항목 | 제안 |
|---|---|
| 센서 | 기체에 실제로 달 BNO085(아비오닉스 선반 위치). 스탠드에 IMU를 따로 붙이는 방식은 참고값으로만 쓴다 |
| 읽는 값 | 선형 가속도 3축과 각속도 3축 |
| 보고 주기 | BNO085가 허용하는 가장 짧은 주기. 정한 값을 로그에 적는다 |
| 스로틀 지점 | 0 %(모터 정지, 기준), 20 %, 40 %, 60 % |
| 구간 | 지점마다 5초. 스로틀을 올린 직후 1초는 버리고 나머지로 계산한다 |
| 계산 | 축마다 평균을 뺀 RMS와 세 축의 합성 RMS. 합성 RMS는 세 축 RMS 제곱의 합의 제곱근이다 |
| 기록 | 원시 로그를 `data/YYYY-MM-DD_TC-0_vibration.csv`로 올린다 |

0 % 기준값이 있어야 "모터가 돌 때 늘어난 만큼"을 볼 수 있다.

## 3. X를 정하는 규칙 (제안)

1. **첫 측정(관찰 모드):** 합격·불합격을 내지 않는다. §4 표만 채운다.
2. **두 번째 측정부터:** 아래 두 조건을 모두 만족하면 합격이다.
   - (a) 스로틀 지점의 합성 RMS가 0 % 기준값의 k배 이하다. k는 첫 측정 뒤에 정한다.
   - (b) IMU 잡음이 복원 판정 띠 2°(마스터 설계 §11.1)를 넘기지 않는다. 확인 방법은 #307, #317이 정한다.
3. X의 숫자는 첫 측정 값과 k로 계산해서 마스터 설계 §11의 TC-0 줄에 적는다. 그 PR은 이 문서가 승인된 뒤에 연다.

## 4. 첫 측정에서 채울 표

| 스로틀 | 보고 주기(ms) | 가속도 합성 RMS (m/s²) | 각속도 합성 RMS (°/s) | 이상음·열·유격 |
|---|---|---|---|---|
| 0 % | □ | □ | □ | □ |
| 20 % | □ | □ | □ | □ |
| 40 % | □ | □ | □ | □ |
| 60 % | □ | □ | □ | □ |

□는 직접 재서 채운다. 짐작해서 채우지 않는다.

## 5. 필요한 코드 변경

가속도와 각속도를 읽어 CSV로 내는 스케치가 없다. 새 이슈로 만든다. 그 스케치가 먼저 있어야 이 방법으로 잴 수 있다.

## 6. 부장이 정할 것

1. 측정 대상을 "제어에 쓰는 IMU의 가속도와 각속도"로 해도 되는지.
2. 첫 측정을 관찰 모드로 하고 X를 그 값으로 정해도 되는지.
3. 전원을 넣는 시험이므로 실행 조건은 `AGENTS.md` §안전 원칙을 따른다. 구속 스탠드(M1)가 없으면 TC-0을 하지 못한다(#256).
