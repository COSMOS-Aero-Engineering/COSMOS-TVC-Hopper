# 11/22 발표 구성안 (#399, 초안)

**상태: 초안이다.** AI가 2026-11-13에 이슈와 PR을 읽고 썼다. 발표의 범위(구속 시험대 실측을 낼지)는 #258의 판정에 달려 있고 부장과 차장이 아직 정하지 않았다. 아래는 모두 제안이다.

**결론(제안):** 발표는 "PD와 RL의 비교표는 시뮬레이션 결과이고, 실물은 부품이 움직이는 것까지 확인했다"로 간다. 이유는 탄소관이 없어서 프레임과 구속 시험대를 만들지 못한 상태가 11/16 데이터 동결까지 풀리기 어렵다고 보기 때문이다(#232, #258 초안 §3 G1). 시험 카드(TC-0부터 TC-5)는 발표에서 "다음 단계"로 둔다.

## 3. 한계 슬라이드에 적을 것

- PD와 RL 비교는 시뮬레이션이다. 실기 성능이라고 말하지 않는다.
- `CL`, `vane_arm_l`, `mass`, 관성은 실측 전이다(`docs/execution/STATUS.md`).
- `Kf`는 잠정값이다(실험 A 미실시).
- 서보는 SG90이고 베인 힌지모멘트 여유는 가정이 많은 예비 계산이다(#382).
- 시뮬레이션에는 센서 잡음, EDF 진동, 구속 스탠드 마찰이 완전히 들어 있지 않다.
- 지도교사 서명은 부장이 받았다고 알렸고 AI는 확인하지 못했다.
