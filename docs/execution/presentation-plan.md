# 11/22 발표 구성안 (#399, 초안)

**상태: 초안이다.** AI가 2026-11-13에 처음 썼고 2026-11-21에 현재 저장소와 이슈 기록에 맞춰 고쳤다. 발표 범위는 #258의 판정에 달려 있다. #258의 [`countdown-1122.md`](countdown-1122.md) §5 "결정" 칸은 2026-11-21에도 비어 있다. 아래는 모두 제안이고, 결정은 부장(`MINBBBB1201`)과 차장(`junwonkim07`)이 한다.

**결론(제안):** 발표는 "PD, PID, RL 비교표는 시뮬레이션 결과이고, 실물은 부품이 움직이는 것까지 확인했다"로 간다. 이유는 2026-11-21에 프레임과 구속 시험대가 없고, 실험 A와 PHASE 1 로그가 `data/`와 이슈에 없기 때문이다. 시험 카드(TC-0부터 TC-5)는 "다음 단계"로 둔다. 구속 시험대 비교는 계속 목표다(#418).

## 3. 한계 슬라이드에 적을 것

실측이 아닌 것을 모두 적는다.

- PD, PID, PPO 비교는 시뮬레이션이다. 실기 성능이 아니다.
- `CL`, `vane_arm_l`, `mass`, `Kf`는 실측 전이다(`docs/execution/STATUS.md`). `Kf`는 잠정값 `1.1e-6`이다(실험 A 미실시). 관성 `Jxx/Jyy/Jzz`도 `params.yaml`의 PLACEHOLDER다(`data/README.md`).
- PID 게인(kp=28, kd=8, ki=2.5)은 시뮬레이션의 튜닝 seed에서 골랐다. 실물에서 시험하지 않았다. PD 행(kp=8, kd=2)은 튜닝하지 않은 기준값이다.
- PD와 PID는 요를 제어하지 않는다. PPO의 평균 리턴이 PID보다 큰 차이는 대부분 요 항이다(`docs/decisions.md` "발표 비교표의 기준 제어기").
- 비교 조건은 구속 상태의 자세 안정화다. 시험하지 않은 것: 학습 분포 밖의 초기 각속도, 40° 넘는 기울기, 센서 잡음, EDF 진동, 구속 스탠드 마찰(`ppo-ablation.md`).
- Stage 2에서 PPO는 착륙하지 못했다(0/100). 이 결과를 내면 한계로 함께 낸다.
- 서보는 SG90이고 베인 힌지모멘트 여유는 가정이 많은 예비 계산이다(#382 댓글 2026-11-13). #382는 11/21에 다른 에이전트가 맡았으므로 슬라이드에 쓰기 전에 값이 바뀌었는지 확인한다.
- 지도교사 서명은 부장이 받았다고 알렸고 AI는 문서를 확인하지 못했다(#236).
