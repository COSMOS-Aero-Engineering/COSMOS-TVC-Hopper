이 문서 하나만 보고 따라간다. 모르는 단어는 각 단계의 "확인" 줄을 먼저 본다.

**오늘 하는 일 세 가지**

1. 받은 프린트 부품이 발주한 31개와 맞는지 센다.
2. 부품마다 무게를 잰다. 지금 계산서에 든 무게는 전부 추정값이라 실측값으로 바꾼다.
3. 서보·EDF·베인이 프린트 부품에 실제로 맞는지 끼워 본다.

**오늘 안 하는 일**

- 배터리를 연결하지 않는다. ESC와 EDF에 전원을 넣지 않는다. 지도교사 서명을 아직 확인하지 못했다(AGENTS.md §안전 원칙).

- 접착제를 쓰지 않는다. 오늘 끼운 것은 전부 다시 뺀다.

## 3. 단계별 절차

### 1단계. 브리핑과 안전 확인 (5분)

1. 부장이 "오늘 안 하는 일" 세 가지를 읽는다.
2. 배터리와 ESC를 책상에서 치운다. 오늘 쓰지 않는다.
   - 확인: 책상 위에 배터리가 없다.
3. 프린트 부품을 큰 종이 위에 전부 펼친다.
   - 확인: 사진 1장을 찍는다. 이 사진이 입고 증거다.

### 2단계. 수량 검수와 분류 (10분)

발주 내용은 파일 31개를 각각 한 번씩 출력한 것이다(`cad/reports/2026-10-21/README.md`).

1. 아래 표의 종류별로 지퍼백에 나눠 담고 유성펜으로 이름을 적는다.

   | 이름 | 발주 수량 | 생김새 | 받은 수 |
   |---|---:|---|---|
   | 베인링 | 1 | 가장 큰 부품. 원통 둘레에 네모 상자 4개가 튀어나와 있다 | |
   | 상판 | 1 | 납작한 도넛 판. 가운데 큰 구멍 | |
   | EDF 클램프 반쪽 | 2 | C자로 휜 띠 2개 | |
   | 배터리 선반 | 1 | 네모 판. 긴 구멍(스트랩용) 4개 | |
   | 전자부 선반 | 1 | 네모 판. 나사 자리 기둥 4개가 솟아 있다 | |
   | ESC 브래킷 | 1 | 작은 ㄱ자 판 | |
   | 베인 | 8 | 납작한 판 가운데가 둥글게 두껍다. 4개는 예비 | |
   | 기본 커플러 | 8 | 짧은 원통. 한쪽에 일자 홈 | |
   | 여유 0.4 mm 커플러 | 4 | 기본 커플러와 겉모습이 같다 | |
   | 발 범퍼 | 4 | 작은 원통 또는 캡 | |
   | 합계 | 31 | | |

2. 커플러 12개를 두 종류로 가른다. 겉모습으로는 구분되지 않는다. 캘리퍼스로 일자 홈의 폭을 잰다.
   - 홈이 넓은 쪽 4개가 여유 0.4 mm 커플러다. 좁은 쪽 8개가 기본이다.
   - 두 값의 차이가 0.4 mm 근처면 맞다. 차이가 거의 없으면 "구분 실패"라고 적고 12개를 한 봉지에 담는다.
   - 확인: 봉지 2개에 각각 홈 폭 숫자를 적었다.
3. 깨짐, 층 분리, 휨, 서포트가 안 떨어진 부품을 따로 모아 사진을 찍는다.
   - 확인: 불량이 없으면 "불량 0"이라고 적는다.
4. 합계를 센다.
   - 확인: 31이면 통과다. 31이 아니면 부족한 이름과 개수를 이슈 #233 댓글에 적는다. 업체에 말할 근거가 된다.

### 3단계. 질량 실측 (15분)

지금 `cad/cg/parts.csv`의 프린트 부품 질량 9줄은 전부 `LOWER_BOUND ESTIMATE`다. 인필만 계산했고 벽과 상하면을 뺐다. 그래서 실제보다 작다. 오늘 잰 값이 이 자리를 대신한다.

1. 저울에 아무것도 없는 상태에서 영점을 맞춘다.
   - 확인: 화면이 0.0 g이다.
2. 아래 순서로 **하나씩** 잰다. 같은 종류가 여러 개면 전부 따로 잰다.
   1. 베인링 2. 상판 3. EDF 클램프(반쪽 하나씩 2번) 4. 배터리 선반 5. 전자부 선반 6. ESC 브래킷 7. 베인 8개 8. 기본 커플러 8개 9. 여유 커플러 4개 10. 발 범퍼 4개
3. 값을 CSV의 `mass_g` 칸에 적는다. 소수 첫째 자리까지 적는다.
   - 확인: 31줄이 다 찼다.
4. 같은 종류끼리 값이 많이 다르면(예: 베인 8개 중 하나만 2 g 차이) 그 부품 번호를 `notes`에 적는다.
5. 전체 합계를 낸다. 종이에 적는다.
   - 확인: 합계가 CSV 맨 아래 `TOTAL` 줄과 같다.

**예상과 다를 때**: 예비를 뺀 본체용 19개의 추정 합계는 약 128 g이다(cad/cg/parts.csv 의 프린트 9줄). 같은 19개를 실측한 합계는 이보다 크게 나온다. 추정값이 벽과 상하면을 뺀 하한이기 때문이다. 추정값보다 **작게** 나오면 저울 단위나 부품 이름을 잘못 적었을 가능성이 크다. 다시 잰다. 예비까지 포함한 31개 전체 합계는 128 g 과 비교하지 않는다. 비교 대상이 다르다.

### 4단계. 체결 확인 (15분)

세 가지를 동시에 진행한다. 서로 다른 책상에서 한다.

#### 4-1. 베인과 베인링 (이민우)

1. 베인 1개를 베인링 안쪽에서 벽의 가로 창(슬롯)에 끝을 넣는다.
   - 확인: 손으로 밀어 넣어진다. 안 들어가면 창의 폭과 베인 끝 두께를 재서 적고 멈춘다.
2. Ø3 탄소봉이 있으면 베인 가운데 구멍과 링 벽 구멍을 지나게 끼운다. 없으면 이 단계를 건너뛴다.
3. 베인을 손으로 좌우로 돌린다. 더 안 돌아가는 지점이 양쪽에 있다.
   - 확인: 그 두 지점 사이 각도를 각도기로 잰다. 설계값은 양쪽 각 15도, 합쳐서 30도다.
   - 25도보다 작거나 35도보다 크면 숫자를 적고 사진을 찍는다. 설계 수정 근거가 된다.
4. 뺀다. 베인 8개 중 2개만 확인한다. 전부 하지 않는다.

#### 4-2. MG90S 서보와 베인링 보스 (김시우, 이경환)

이 단계가 #219의 핵심이다. 서보가 안 맞으면 베인링을 다시 출력해야 한다.

1. 서보의 전원선이 아무 데도 꽂혀 있지 않은지 본다.
   - 확인: 선 끝이 공중에 떠 있다.
2. 캘리퍼스로 세 가지를 재서 CSV에 적는다.
   - 귀 구멍 2개의 중심 사이 거리(설계 가정 28.0 mm)
   - 출력축 중심에서 가까운 쪽 귀 구멍 중심까지 거리(설계 가정 9.9 mm)
   - 혼(서보에 끼우는 플라스틱 팔) 두께와 폭(설계 가정 두께 2.2 mm, 폭 9.0 mm)
3. 서보를 베인링 바깥쪽 네모 상자(보스)의 바깥면에 얹는다. 나사는 조이지 않는다.
   - 확인: 귀 구멍 2개가 상자의 구멍 2개와 겹친다. 출력축이 가운데 둥근 구멍으로 들어간다.
4. 혼을 서보에 끼우고, 커플러의 일자 홈에 혼을 넣어 본다.
   - 확인: 기본 커플러와 여유 커플러 중 어느 쪽이 들어가는지 적는다. 둘 다 안 들어가면 혼 두께 값을 적고 멈춘다.
5. 결과를 `맞음` 또는 `안 맞음`으로 적는다. 안 맞으면 어긋난 거리를 mm로 적는다.

#### 4-3. EDF 클램프와 EDF 본체 (김민찬)

1. EDF 본체의 둘레가 가장 넓은 부분(흡입구 쪽)에 클램프 반쪽 2개를 감싼다.
2. 양쪽 탭(귀처럼 나온 부분)이 만나는 틈을 캘리퍼스로 잰다.
   - 확인: 틈이 양쪽 모두 0보다 크고 6 mm보다 작으면 조일 수 있다. 틈이 0이면 클램프가 크고, 6 mm보다 넓으면 볼트가 닿지 않는다. 숫자를 적는다.
3. EDF 하우징 외경을 줄자나 캘리퍼스로 다시 잰다. CAD는 72 mm로 가정했다.
   - 확인: 측정값을 적는다. 72 mm와 1 mm 넘게 다르면 이슈 #233에 적는다.

### 5단계. EDF 배기 치수 실측 (7분, #118)

전원을 넣지 않는다. 자와 캘리퍼스만 쓴다.

1. EDF 뒤쪽(배기구) 안지름을 잰다.
2. 가운데 모터를 덮은 원뿔(허브)의 가장 굵은 지름을 잰다.
3. 두 값을 CSV의 `edf_exit_id_mm`, `edf_hub_od_mm` 행에 적는다.
   - 확인: 두 값이 모두 0보다 크고 배기 내경이 허브보다 크다.

이 두 값은 베인이 실제로 바람을 받는 면적을 정하는 숫자다. 지금 시뮬레이션은 추정값(잠긴 구간 4-32 mm, 반지름 18 mm)을 쓴다.

### 6단계. 기록 마감 (8분)

1. CSV를 저장한다. 파일 이름은 `data/2026-10-30_print-intake.csv`다.
2. 사진을 이슈 #233 댓글에 올린다. 최소 3장이다: 전체 펼친 사진, 불량(없으면 생략), 서보를 보스에 얹은 사진.
3. 댓글에 세 줄을 쓴다.
   - 한 일: 검수 31개 중 몇 개 확인, 질량 몇 줄, 체결 몇 건
   - 막힌 것: 안 맞은 항목과 숫자
   - 다음: 누가 무엇을 하는지
4. 부품을 봉지에 다시 담는다. 봉지를 한 상자에 모은다.
   - 확인: 책상에 남은 부품이 없다.

## 4. 기록 양식

`data/2026-10-30_print-intake.csv`를 연다. 칸 뜻은 아래와 같다.

| 칸 | 뜻 | 예 |
|---|---|---|
| `item` | 부품 이름. 2단계 표의 이름을 그대로 쓴다 | `vane_3` |
| `kind` | `mass`(질량), `fit`(체결), `dim`(치수) 중 하나 | `mass` |
| `value` | 잰 값. 숫자만 쓴다 | `12.4` |
| `unit` | `g` 또는 `mm` 또는 `deg` | `g` |
| `result` | 체결 판정. `ok`, `ng`, `skip` 중 하나. 질량 행은 비운다 | `ok` |
| `measured_by` | 잰 사람 이름 | `박지훈` |
| `notes` | 이상한 점, 건너뛴 이유 | `서포트 자국 남음` |

값을 모르면 칸을 비운다. 추측해서 채우지 않는다.

- 실제 출력물의 치수가 STL과 같은지 확인하지 않았다. 10/30에 캘리퍼스로 처음 잰다.
- 프린트 부품의 강도를 확인하지 않았다. 질량과 체결만 본다.
- 동아리 시간이 60분인지 확인하지 않았다. 60분으로 가정하고 짰다. 시간이 다르면 2단계 표의 시각을 바꾼다.
