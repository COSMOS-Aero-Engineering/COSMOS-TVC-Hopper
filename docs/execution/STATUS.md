**막혀 있는 것**
1. **탄소관이 없다.** 구매 대장(2026-11-08)에서 D1/D2가 미확보다(#232). 프레임 조립(#375), 구속 스탠드 제작(#378), 시험 카드 TC-0부터 TC-5(#392-#397)가 보류다.
2. **실험 A를 하지 않았다.** `Kf`는 잠정값이다. 스로틀 상한을 푸는 PR #369가 승인을 기다린다(#237, #244).
3. **구속 스탠드(M1)의 구성을 정하지 않았다.** 초안은 PR #372다(#256).
4. **IMU를 SPI로 할지 I2C로 할지 정하지 않았다.** 설계는 SPI이고 지금 동작하는 것은 I2C 18, 19다. 이 핀은 설계상 RC 입력과 겹친다(#245). 비행용 만능기판 납땜이 이 결정과 부품(암헤더, IMU 소켓, 에나멜선)을 기다린다(#383).
5. **밸런스 충전기를 갖고 있지 않다.** LiPo 충전은 보류다(#251). 2핀 커넥터 등 구매 대장에 없는 부품이 있다(#385).
6. **일정 결정이 비어 있다.** 11/16에 데이터를 동결하고 11/22에 발표한다. 축소 경로 판정 G1-G3은 부장과 차장의 결정을 기다린다(#258).
7. **SG90이 베인 힌지모멘트를 감당하는지는 실측 전이다.** 예비 계산은 4-20배 여유로 나왔지만 가정이 많다(#382, TC-2 #263).

- DShot 벤치 펌웨어(`throttle_serial`): arm 게이트, 상한 DShot 600, 램프, 워치독, 비상정지. **ESC 없이 Teensy에서만 확인**(#19). 실물 시험은 #24.
- Stage 1 시뮬레이션(`sim/sim_stage1`)과 PPO 파이프라인, 에피소드를 웹 CSV로 내보내는 `export_episode.py`(#23).
- KiCad 회로도 생성(20부품, 30넷). ERC 첫 실행(10/17, 오류 4개·경고 129개). 같은 날 넷리스트 대조로 생성기 핀 좌표 Y축 반전 결함을 찾음(#66). **이 회로도로 배선하지 않는다** — 부품 20개가 모두 뒤집혀서 배터리·UBEC·Teensy 전원·ESC의 극성이 반대다.

**막혀 있는 것**
1. **실험 A(EDF 추력곡선) 미실시.** `Kf`(추력 상수)가 잠정값 `1.1e-6`(10 N 역산)이다.
2. **시뮬레이션 베인 제어력의 CL과 `vane_arm_l`이 추정값이다.** 베인 제어력 버그(#21)는 2026-10-16에 **PR #35** 머지로 고쳤다. 이 머지로 #27이 닫혔다. #21은 같은 날 머지 전에 #27의 중복으로 닫혔다. PR #35는 CL을 논문 식 3.16으로 다시 계산하고 `vane_arm_l`을 0.104 m로 바꿨다. 도메인 랜덤화를 켠 PD 200 에피소드 합격 기준(넘어짐 ≤ 5 %, 최종 기울기 중앙값 ≤ 5°)은 `python tasks.py check`의 `gate` 단계가 PR마다 확인한다. PR #35의 결과는 넘어짐 0 %였다. CL과 `vane_arm_l`은 실측 전이라(#26 무게중심, TC-2) **RL 결과를 실기 성능으로 해석하지 않는다.** PPO가 PD보다 못한 원인은 #90에서 찾는다. 남은 일: [`docs/tasks/27-sim-vane-authority.md`](../tasks/27-sim-vane-authority.md).
3. **3D프린트 발주본 R2 제공**(10/21, #224). 업체가 선반 고정부의 박육을 지적해 두 선반을 수정했다. R2는 독립 STL 31개를 각각 1개씩 출력하는 묶음이다. 기존 주문·배치를 전체 대체하며 구버전과 합산하지 않는다. [수량과 검사](../../cad/reports/2026-10-21/README.md)를 참고한다. 업체의 R2 교체·출력 착수 여부는 아직 확인하지 않았다. 입고 뒤 실제 출력물 질량, 체결, 조립 CG는 #219에서 확인한다.
4. **IMU Yaw**가 돌린 만큼 안 변한다. 스케치가 지자기를 쓰는 Rotation Vector 모드인데 설계는 자력계를 안 쓰기로 했다. Game Rotation Vector로 비교 예정(#28).
