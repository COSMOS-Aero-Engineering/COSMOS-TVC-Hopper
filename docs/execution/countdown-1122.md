# 11/22 발표까지 주별 역산 일정과 축소 경로 판정 (초안, #258)

**상태: 검토 전 초안이다.** AI가 2026-10-31에 이슈 기록으로 썼다. 아래 판정 기준, 판정 날짜, 최소 결과물은 모두 **제안**이다. 부장(`MINBBBB1201`)과 차장(`junwonkim07`)이 #258에 검토 댓글을 쓰고 §5 표의 "결정" 칸을 채우면 확정한다.

**결론(제안):** 남은 3주 안에 구속 시험대에서 PD와 RL을 비교(TC-3-TC-5)하기는 어렵다고 본다. 근거는 §1이다. 그래서 발표의 PD와 RL 비교표는 시뮬레이션 결과로 내는 쪽을 제안한다. 실물 결과는 실험 A 추력 곡선과 축소 경로 PHASE 1(IMU 롤로 서보 1개를 움직임) 동작 기록이다. 11/2(월)에 탄소관과 서보 수를 보고 이 방향을 확정한다(§3 G1).

## 1. 지금 상태 (2026-10-31)

확인한 사실(출처는 괄호):

- 9/20 계획의 날짜는 TC-0-TC-2 10/12-10/26, TC-3·TC-4 10/26-11/2, RL 실기 이식 11/2-11/9, TC-5 11/8, 발표 준비 11/9-11/22, 최종 발표 11/22다([`TIMELINE.md`](TIMELINE.md) 간트차트). 같은 문서는 실제 진행이 약 3주 늦다고 적는다.
- 프레임을 세우지 못했다. 기둥·다리용 Ø6 탄소관을 구매하지 않았다(#232).
- 서보는 SG90 2개가 있다. 정본은 MG90S 4개(예비 포함 6개)다. 부장은 2026-10-31에 "지금 있는 2개로 진행한다"고 정했다(#260 닫힘 댓글).
- 3D 프린트 R2 31개는 10/29에 들어왔다(#233, #242).
- `Kf`는 잠정값 `1.1e-6`이다. 실험 A를 하지 않았다(#244). `throttle_serial`의 스로틀 상한은 27.6 %다(#237).
- DShot 펌웨어는 ESC 없이 Teensy에서만 확인했다. 실물 ESC 시험이 남았다(#24).
- 지도교사 서명은 부장이 2026-10-29에 받았다고 알렸다. AI는 서명 문서를 확인하지 않았다(#236).
- 구속 스탠드(M1)는 설계 파일이 없다(#256). TC-0, 1, 2.5, 3, 4, 5는 모두 M1을 쓴다([마스터 설계](../design/00-hopper-master-design.md) §11).
- TC-0 합격 기준의 진동 한계 X가 비어 있다(#253).
- IMU는 I2C로 동작한다. SPI와 I2C 중 무엇을 쓸지 정하지 않았다(#245).
- 시뮬레이션에서 PPO는 PD보다 못하다. 평가 seed 200개에서 PD는 최종 기울기 중앙값 2.5°, PPO는 13.8°다. PPO는 스텝의 90.4 %에서 스로틀 0을 냈다([`ppo-diagnosis.md`](../../sim/sim_stage1/ppo-diagnosis.md)). 이 지름길을 막는 일은 #230이 맡는다.
- `sim_stage1`의 PD와 PPO 비교(`pd_gate.py`, `ppo_diagnosis.py`)는 넘어짐 비율과 최종 기울기 중앙값만 낸다. 복원시간, 오버슈트, 정상오차는 커넥톰 트랙의 `sim/connectome/evaluate.py`가 계산한다(복원 판정 2°). 이 함수로 `sim_stage1`의 PD와 PPO를 seed 200개에서 비교한 표는 아직 없다.
- 축소 경로는 PHASE 0 스로틀만으로 시소 균형, PHASE 1 서보 1개, PHASE 2 PID 자리에 RL이다(`AGENTS.md` §확정된 방향).

추론(근거와 함께):

- 구속 시험대 비교(TC-5)에는 프레임, 서보 4개, M1, 킬스위치가 연결된 RC 수신기, 실물 ESC 시험, 실험 A가 모두 필요하다. 2026-10-31에 이 중 끝난 것이 없다. TC-1은 베인 4개의 부호를 보므로 서보 2개로는 할 수 없다. 그래서 11/16까지 TC-5 데이터를 얻기는 어렵다고 본다.
- PHASE 1은 모터를 쓰지 않는다. 그래서 PHASE 1만으로는 닫힌 루프 자세 제어의 PD와 RL 비교가 되지 않는다. PHASE 1은 "센서에서 서보까지 연결이 맞다"는 증거다.

아직 확인하지 못한 것:

- PHASE 0의 시소 구조물을 정의한 문서가 저장소에 없다. 무엇을 축으로 무엇을 매다는지 모른다. PHASE 0은 EDF에 전원을 넣는다.
- 추력 스탠드, 저울이나 로드셀, 수신기와 조종기, 킬스위치 정격(#242, #244, #236).
- 동아리 활동 요일. 이 문서는 주 단위로만 쓴다.

## 3. 축소 경로로 바꾸는 기준과 판정 날짜

판정 날짜에 조건을 보고, 조건에 맞으면 오른쪽으로 바꾼다. Shape Up의 circuit breaker처럼 기한을 기본으로 늘리지 않는다(근거 §6). 안 된 일은 다음 학기로 넘긴다.

| 판정 | 날짜 | 조건 | 바꾸는 것 |
|---|---|---|---|
| **G1** | 11/2(월) | 탄소관이 11/9까지 오지 않거나, MG90S가 4개가 안 된다. | 프레임 조립과 M1 기체 시험(TC-0-TC-5)을 이번 학기 범위에서 뺀다. 실물은 PHASE 1로 간다. 비교표는 시뮬레이션으로 낸다(§4 안). |
| **G2** | 11/8(일) | 실험 A 원시 로그가 `data/`에 없다. | `Kf`를 잠정값으로 두고, 비교표에 "`Kf` 잠정값 기준"이라고 적는다. PHASE 0은 EDF 전원이 필요하므로 뺀다. |
| **G3** | 11/12(목) | IMU 롤을 기울이면 서보가 정한 부호로 움직이는 로그가 없다(#257). | 실물 결과는 브링업 기록(IMU 5자세, 서보 보정, 실물 ESC 시험)만 낸다. |
| **G4** | 11/12(목) | PPO가 스로틀 0 지름길을 막은 뒤에도 PD 합격 기준(넘어짐 ≤ 5 %, 최종 기울기 중앙값 ≤ 5°)을 넘지 못한다(#230). | 실험을 바꾸지 않는다. 비교표에 그 결과와 원인 분석(#90)을 그대로 낸다. "RL이 낫다"를 전제하지 않는다(`AGENTS.md` §프로젝트 한눈에). |
| **G5** | 11/16(월) | 날짜만 본다. | 데이터를 동결한다. 이후에는 발표 자료와 리허설만 한다. |

PHASE 2(실물 Teensy에서 PID 자리에 RL)는 이번 학기에 하지 않는 쪽을 제안한다. Teensy에서 정책을 추론하는 코드가 없고([03 문서](../design/03-control-pipeline-design.md) §6은 방법만 적었다), PHASE 1에는 추력이 없어서 비교할 동역학이 없다.

## 4. 발표에 낼 최소 결과물 (제안)

> PD와 RL의 비교표는 구속 시험대 실측이 아니라 시뮬레이션(`sim_stage1`, 도메인 랜덤화 켬, 같은 평가 seed 200개) 결과로 내고, 실물은 실험 A 추력 곡선과 PHASE 1(IMU 롤로 서보 1개, 모터 없음) 동작 로그로 낸다.

- 비교표의 지표는 마스터 설계 §11 TC-3과 같은 복원시간, 오버슈트, 정상오차에 넘어짐 비율을 더한다. `sim/connectome/evaluate.py`의 계산을 `sim_stage1`의 PD와 PPO에 쓰는 일은 #266이 맡는다.
- 발표에서 시뮬레이션 결과를 실기 성능이라고 말하지 않는다. Stage 1은 파이프라인 검증용이고 최종 학습 결과로 쓰지 않는다([03 문서](../design/03-control-pipeline-design.md) §1). `CL`, `vane_arm_l`, `mass`는 아직 실측이 아니다(`STATUS.md`).
- G1을 통과해도 11/16까지 TC-3-TC-5를 모두 하기는 어렵다고 본다(§1 추론). G1을 통과하면 TC-0까지를 실물 추가 결과로 낼지 검토자가 정한다.
