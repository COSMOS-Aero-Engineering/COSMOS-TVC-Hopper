# 첫 전원 시험 절차서 (P1-P8)와 킬 2중 확인 (#398, 초안)

**상태: 초안이다.** AI가 2026-11-13에 설계 문서를 읽고 썼고 부장(`MINBBBB1201`)과 지도교사의 검토 전이다. 이 절차서는 전원을 넣는 시험(실험 A, TC-0, TC-1, TC-3)을 하는 날 한 장으로 따라 하려고 만들었다.

**결론(제안):** 전원은 위에서 아래로 한 단계씩만 올린다. 앞 단계의 합격 기준을 눈으로 확인하기 전에는 다음으로 넘어가지 않는다. 킬은 두 갈래(조종기 킬 채널, 물리 킬스위치)를 시험 전에 각각 동작시켜 본다.

## 1. 먼저 지킬 것

확인한 사실(출처는 괄호):

- 지도교사 서명 전에는 EDF에 전원을 넣지 않는다. 부장이 2026-10-29에 서명을 받았다고 알렸다. AI는 서명 문서를 확인하지 않았다(`AGENTS.md` §안전 원칙, #236).
- 전원과 회전 시험은 구속, 방호, 킬 경로를 확인한 뒤 부장이 입회해서 한다(`docs/execution/hopper-integration.md`).
- 첫 회전 시험은 EDF 팬을 분리하거나 추력 스탠드에 볼트로 고정한 상태에서만 한다(`firmware/cosmos/throttle_serial` 헤더, #24).
- 모든 단계에서 손은 킬스위치에, 사람은 배기 축선 밖에, 배터리는 30초 이상 연속 방전하지 않는다(`docs/design/01-avionics-integration-final.md` §10).
- 배선을 바꿀 때는 항상 배터리를 물리적으로 분리한다. 킬스위치만 믿지 않는다(§4.4).
- 빵판 단계의 최고 전압은 5 V이다. 4S(16.8 V) 배선은 빵판을 지나지 않는다(§4.4).

## 2. 역할 (세 사람은 서로 달라야 한다)

| 역할 | 하는 일 |
|---|---|
| 스로틀 담당 | 시리얼에서 `arm`과 스로틀 숫자를 입력한다. 빈 줄 Enter가 비상정지다 |
| 킬 담당 | 손을 킬스위치에서 떼지 않는다. 이상이면 말 없이 바로 내린다 |
| 기록 담당 | 단계마다 합격 여부, 시각, 값을 적는다. 로그 파일을 저장한다 |

입회자(부장, 지도교사)는 이 세 사람과 따로 있다. 배기 축선 밖에 선다.

## 3. 시작 전 확인표 (§9-7)

모두 눈으로 확인하고 체크한다. 하나라도 아니면 시작하지 않는다.

- [ ] 킬스위치 OFF
- [ ] 5 V와 GND 사이 단락 없음(멀티미터)
- [ ] 배터리 극성
- [ ] 팬 경로에 손, 공구, 종이가 없음
- [ ] 흡·배기 그릴 장착, 방호판 설치
- [ ] 보안경(참석자 전원)
- [ ] 소화기 위치 확인, 세이프백 준비
- [ ] 지도교사 서명된 안전계획서 확인(부장)
- [ ] 스탠드에 EDF 볼트 고정, 손으로 흔들어 움직이지 않음

## 4. 킬 2중 확인

킬은 두 갈래다. 조종기 킬 채널이 1차, 물리 킬스위치가 2차다(`docs/execution/procurement-review.md` B6).

1. **조종기 킬:** 배터리 메인을 연결하지 않은 상태에서 수신기와 Teensy만 켜고, 킬 스위치를 내렸을 때 시리얼에 `KILL`이 나오는지 본다(`rc_bench`, #275).
2. **물리 킬스위치:** 멀티미터를 도통 모드로 놓고 스위치 ON에서 이어지고 OFF에서 끊어지는지 본다(#250).
3. 두 가지 모두 **시험 날마다** 다시 한다. 전날 확인한 것을 쓰지 않는다.

## 5. 단계표 (P1-P8)

| 단계 | 하는 일 | 합격 기준 | 실패하면 |
|---|---|---|---|
| P1 | Teensy만 USB로 연결 | 시리얼에 시작 메시지가 나온다 | 충전 전용 USB 케이블인지, 보드 인식 확인 |
| P2 | IMU 출력 확인(기체 정지) | 롤, 피치가 ±0.5° 안에서 안정. 손으로 기울이면 부호가 맞다 | I2C 또는 SPI 배선 확인(#245) |
| P3 | 수신기와 UBEC ON(**배터리 메인은 아직 OFF**) | 5채널 펄스폭 1000-2000 µs. 킬 스위치를 내리면 스로틀 0 처리 | 레벨시프터, GND 확인 |
| P4 | 서보 4개 동작(모터 없이) | 명령각과 실제 베인 방향 일치. 스톨음과 발열 없음 | 혼 각도 재장착, 부호 반전 |
| P5 | EDF를 스탠드에 볼트 고정한 상태에서 배터리 연결 | ESC 아밍음 정상. 스로틀 0에서 무회전 | 즉시 킬 |
| P6 | 스로틀 10 % 5초 | 이상음, 진동, 연기 없음. 배기가 아래로 나간다 | 3상 중 2선 교체 |
| P7 | 10 %씩 올림(실험 A) | 각 점에서 추력, 전류 기록 | 온도나 전류가 한계에 가까우면 중단 |
| P8 | 기체를 구속 스탠드(M1)에 걸고 TC-0 | 마스터 설계 §11 시험 카드대로 | - |

첫 전원 인가 순서는 ① USB로 Teensy만, 시리얼 확인 ② UBEC와 수신기 ③ 마지막에 배터리 메인이다(§4.4).

## 6. 시험별로 쓰는 단계

| 시험 | 단계 | 비고 |
|---|---|---|
| DShot 실물 ESC 시험(#24) | P1, P3, P5 | **팬 분리** 상태. 시험표 8개 항목은 `docs/tasks/28-dshot-bench.md` |
| 실험 A(#244) | P1-P7 | 스로틀 상한이 27.6 %라서 `limit` 명령이 필요하다(#237, PR #369) |

## 7. 이상이 생기면

| 증상 | 가장 흔한 원인 | 하는 일 |
|---|---|---|
| ESC가 삐 소리만 내고 안 돈다 | Teensy와 ESC의 GND 미연결 | 킬 후 H3의 GND선 확인 |
| 스로틀이 안 먹거나 폭주 | 자동 아밍, 워치독 없음 | **즉시 킬.** 시험 중단 |
| 서보가 떤다 | 5 V 레일이 떨어짐, 신호 레벨 부족 | 킬 후 UBEC 출력 캡, 전원 확인(#388) |
| 수신기가 리셋된다 | 서보 돌입전류로 5 V 딥 | 킬 후 UBEC 용량 확인 |
| 연기, 냄새, 이상음 | - | **즉시 킬, 배터리 분리, 배터리를 금속 위로 옮기고 부장에게 알린다.** 물을 붓지 않는다 |

## 8. 끝낼 때

1. 스로틀 0, 킬스위치 OFF.
2. 배터리를 분리하고 EDF가 완전히 멈출 때까지 기다린다.
3. 배터리를 손으로 만져 온도를 본다. 뜨거우면 세이프백에 넣고 식힌다.
4. 로그를 `data/`에 저장하고 기록 담당이 이슈에 올린다.

## 9. 부장이 정할 것

1. 입회자에 지도교사가 매번 필요한지, 첫 시험만인지.
2. 시험 구역과 시간(장소가 정해지지 않았다).
3. 킬 2중 확인의 합격 기준을 위처럼 두어도 되는지.
