# BOM — 착륙 호퍼 rev C (Teensy 4.0 / SolidGeek 베이스 + 단일 EDF)

`research-open-source-references.md` §6 권장안 채택판. rev B(F405 WING + ArduPilot SingleCopter)에서
**비행 컨트롤러·센서·통신 계통을 SolidGeek/SingleRotorUAV 방식으로 교체**, 추진·구조·안전 계통은 rev B 유지.

> 마스터 설계도는 `00-hopper-master-design.md` rev C로 이미 갱신됨. 이 문서는 그 구매 리스트.
>
> **2026-09 갱신 — 예산형 사양 반영.** 구조·아키텍처(Teensy+BNO08x+단일EDF+베인, SolidGeek 포크)는
> **그대로 두고**, 부품 등급·소싱만 낮춰 rev B와 비슷한 금액대로 맞췄다. 아래 표의 "예산형"이 기본 권장값 —
> 코드 호환성·논문 재현성엔 영향 없음(같은 칩, 같은 프로토콜, 브랜드/용량만 다름).

## 뭐가 바뀌었나 (rev B → rev C)

| 계통 | rev B | **rev C** | 이유 |
|---|---|---|---|
| 비행 컴퓨터 | SpeedyBee F405 WING (ArduPilot) | **Teensy 4.0** (SolidGeek 코드 포크) | CLAUDE.md의 "Teensy 대안"을 검증된 오픈소스로 실현. RL 이식이 쉬운 구조 |
| 자세 센서 | F405 내장 ICM-42688P + SPL-06 바로미터 | **BNO085 IMU 브레이크아웃** (센서퓨전 내장, 쿼터니언 직접 출력) | SolidGeek 코드가 이 칩 기준. 바로미터는 STAGE 1(구속)엔 불필요 → 제외, 홉 단계에서 ToF로 대체 |
| ESC | 60A 4S, BEC만 | **60A 4S, 양방향 DShot(RPM 텔레메트리) 지원 필수** | Bresciani의 자이로스코픽 정차 보정 로직에 로터 RPM이 필요 |
| 텔레메트리 | FC 내장 로깅 | **ESP32 개발보드 추가** (SolidGeek 방식, WiFi 지상국) | 시험 데이터 로깅 = PID/RL 비교의 핵심 산출물 |
| 수신기 | Spektrum 재사용 가정 | 그대로, 단 **Teensy에서 읽는 방식 2가지 중 택1** (아래 B4) | |
| 추진(EDF)·서보·구조·다리·구속·안전 | — | **rev B 그대로 유지** | 이 부분은 아키텍처 무관하게 검증됨 |

**절감 포인트 요약** (구조·코드 호환성엔 영향 없음, 부품 등급/소싱만 변경):
- ESC: 양방향 DShot → 일반 DShot로 시작, 필요시만 나중에 업그레이드 (−10~15k)
- 배터리: 4S 1300mAh×3 → 4S 850mAh×2 (−20~35k, STAGE1엔 런타임 안 중요)
- IMU: Adafruit 정품 → 중국 동일칩 범용 브레이크아웃 (−10~20k)
- ESP32: 지금 생략, Teensy 자체 로깅으로 대체, STAGE2+에 추가 (−6~12k)

이렇게 하면 **rev B와 거의 같은 금액대**로 SolidGeek 논문/코드를 그대로 따라가는 rev C 구조를 살 수 있다.
STAGE 3(홉) 갈 때 B7(ToF, +8~12k)·B8(광류, +15~20k), 필요시 ESC 업그레이드(+10~15k) 추가.

## 구매 순서 권장 (전체를 한 번에 안 사도 됨 — 이 순서대로 나눠 사도 됨)

**1차: A1(EDF) · B1(Teensy 4.0) · B2(IMU) · B9(USB 데이터 케이블) · A2(ESC)** — EDF·Teensy·IMU·ESC의 실물 치수(EDF 하우징 지름·마운트 볼트
간격, 보드 크기)가 CAD의 나머지 부분(모터마운트 소켓 크기, 배선 레이아웃)을 결정하기 때문에 **먼저 사서
실측**해야 그다음 프린트 설계가 정확해진다. B9는 Teensy 실물 업로드와 로그 확인에 바로 필요하다.
나머지(C~G)를 안 사고 이 항목들만 먼저 사도 무방.

2. 핵심 4개 부품 도착 → 실측 → SolidGeek Onshape 포크 모델의 모터마운트 파라미터 교체.
3. **2차**: C(서보)·D(구조 소재) — 프린트/재단 일정에 맞춰 구매.
4. **3차**: F·G(구속·안전) — 아키텍처와 무관해서 언제 사도 되고, 병렬로 준비 가능.
5. B3(ESP32)·B7(ToF)·B8(광류)는 STAGE 1 통과 후 필요할 때.

## 아직 결정 안 된 것

- **CAD를 SolidGeek Onshape에서 포크할지, rev B의 자체 파라메트릭(`cad/*.scad`)을 계속 쓸지** — 포크 쪽이 시간 절약이 크다는 게 리서치 결론이지만 최종 확정은 안 함.
- **수신기 B4-a vs B4-b** — 재고 확인 후 결정.
- 이 BOM 확정 시 `00-hopper-master-design.md`도 rev C로 개정 필요(치수·배선도·펌웨어 섹션 갱신) — 원하면 다음에 진행.
