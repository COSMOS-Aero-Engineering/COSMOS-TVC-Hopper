# 실측값 기록

캘리퍼스로 잰 부품 실측값을 여기 적고, `cad/hopper_params.scad`(정본, 맨 위 `MEASURED` 블록)에
반영한 뒤 커밋한다. (`cad/params.scad`는 `cad/legacy/`로 옮겨진 구버전 — 더 이상 안 씀.)
값을 바꿀 때마다 이 표도 같이 업데이트할 것 — 나중에 "이 숫자가 어디서 나왔는지" 확인할 유일한 근거다.

| 부품 / 위치 | 측정값 (mm) | 측정 방법 | 측정자 | 날짜 | 비고 |
|---|---|---|---|---|---|
| EDF 외경 |  |  |  |  |  |
| EDF 마운트 홀 간격 |  |  |  |  |  |
| Teensy 보드 가로×세로 |  |  |  |  |  |
| 베인(vane) 서보 마운트 폭 |  |  |  |  |  |
| 상판 두께 |  |  |  |  |  |
| 배터리 폭×길이×높이 |  |  |  |  |  |

측정할 때 참고:
- 캘리퍼스 0점(zeroing) 먼저 확인.
- 같은 곳을 2번 재서 값이 다르면 셋째 값까지 재고 중간값 사용.
- 표에 없는 항목이 필요하면 행을 추가하고 커밋 메시지에 `[cad]` 태그 붙이기.
