# 실측값 기록

캘리퍼스로 잰 부품 실측값을 여기 적고, `cad/hopper_params.scad`의 `MEASURED` 블록에 반영한 뒤 커밋한다.
값을 바꿀 때마다 이 표도 같이 업데이트할 것 — 나중에 "이 숫자가 어디서 나왔는지" 확인할 유일한 근거다.

| 부품 / 위치 | 측정값 (mm) | 측정 방법 | 측정자 | 날짜 | 비고 |
|---|---|---|---|---|---|
| EDF 외경 |  |  |  |  |  |
| EDF 마운트 홀 간격 |  |  |  |  |  |
| Teensy 보드 가로×세로 |  |  |  |  |  |
| 베인(vane) 서보 마운트 폭 |  |  |  |  |  | 설계상 MG90S(9g) 확정(마스터 설계 §4) — Week 1 BOM에 실물 없으면 다른 프로젝트에서 쓰던 MG90S로 대체 측정 가능. 실제 구매품 도착 시 몸통 폭만 재대조 |
| 배터리 폭×길이×높이 |  |  |  |  |  |

**상판 두께는 측정 항목 아님** — `cad/print_parts/top_plate.stl`로 3D 프린트할 파츠라 잴 실물이 없다. 마스터 설계 §4에 이미 `top_plate_t = 4mm`로 잡혀 있으니, 그대로 쓸지 강성 보고 바꿀지만 결정해서 `hopper_params.scad`에 반영. (플랜B로 합판 상판을 쓰게 되면 그때만 실측 필요.)

측정할 때 참고:
- 캘리퍼스 0점(zeroing) 먼저 확인.
- 같은 곳을 2번 재서 값이 다르면 셋째 값까지 재고 중간값 사용.
- 표에 없는 항목이 필요하면 행을 추가하고 커밋 메시지에 `[cad]` 태그 붙이기.
