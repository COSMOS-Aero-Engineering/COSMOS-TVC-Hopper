# cad/ — 파라메트릭 CAD

이 폴더의 원칙: **프리핸드 CAD 금지.** 코드 기반 파라메트릭 설계 우선. (예전 `AGENTS.md`에 있던 원칙이다. 2026-09-17 정리에서 `AGENTS.md`에서는 빠졌다.)

## 현재 정본

**[`hopper_params.scad`](hopper_params.scad)** — rev C 오픈 스탠드오프 프레임 전체를 담은 단일 파일.
EDF 실측(2026-09-13, 하우징 외경 72mm·볼트 플랜지 없음 확인) 반영해서 **분할 클램프(collar clamp)
마운트**로 설계됨(원래 볼트 마운트 가정이었던 게 실물과 안 맞아서 변경). 기둥-베인링 반경 불일치, 다리
스태거 미적용 등 구조 버그 2건도 수정된 상태.

- 맨 위 **"MEASURED"** 블록만 실측값. 나머지는 `docs/design/00-hopper-master-design.md` §4 값 그대로.
- 파일 맨 아래 `echo()`들이 조립 정합성을 콘솔에 출력 — 값 바꾼 뒤 OpenSCAD 콘솔에서 반드시 확인.

  `"print"` (실제 프린트 대상 파츠만) 두 모드. **`"print"`로 렌더해도 파츠 9개가 합쳐진 채로 나오니,
  외주용 STL은 모듈 하나씩 남기고 개별 export 필요** — 순서는 [`print_parts/README.md`](print_parts/README.md).

**2026-09-18: 실제로 렌더·export 완료.** 이 PC 바탕화면의 `openscad.exe`(2021.01, 정상 동작 — `Program

## 워크플로

1. [OpenSCAD](https://openscad.org/downloads.html) 설치(무료). `hopper_params.scad` 열고 F5.
2. 부품 실측값이 바뀌면 파일 맨 위 `MEASURED` 블록만 수정 — 나머지는 자동 갱신.
3. 콘솔 `echo()` 출력으로 조립 정합성(클램프가 EDF 몸통 범위 안에 있는지, 트레이가 안 겹치는지 등) 확인.
   명령행에서는 저장소 루트에서 `python tasks.py cad`. echo에 `!!` 경고가 있거나 OpenSCAD가 WARNING·ERROR를
   내면 실패한다. CI도 PR마다 같은 검사를 돌린다(#61). OpenSCAD는 환경변수 `OPENSCAD`, PATH,
   `C:\Program Files\OpenSCAD` 순서로 찾고, 없으면 건너뛴다.
4. 개별 모듈만 남기고 `F6`(Render) → STL export → `print_parts/`에 저장 (순서: [`print_parts/README.md`](print_parts/README.md)).
5. 슬라이서에서 확인(PETG, 인필 40%, 벽 4라인 — PLA 금지, 모터 폐열).
6. 실제 외주 발주 시 그 STL을 `print-orders/<날짜>/`로 복사해서 커밋.

## 좌표 관례

- Z = 0: EDF 배기면(§4 기준면). +Z 위(흡기), −Z 아래(배기).
- 베인 0°(중립) = 시위가 Z축과 평행. 부호는 실기 TC-1에서 정합.

## 완성 모습 렌더 (`showcase.scad`, #59)

`cad/showcase.scad`는 프린트 부품에 구매품(EDF 본체, 배터리, Teensy·IMU 기판, ESC, 서보, 킬스위치)과 배선을 외형만 더한 발표용 장면이다. 프린트 대상이 아니다.

```bash
openscad -o cad/renders/showcase.png --imgsize=1600,1200 --camera=600,-720,420,0,0,30 --projection=p --viewall --autocenter cad/showcase.scad
```

이 렌더에서 확인한 배선 지침:
- 서보선은 가장 가까운 기둥을 타고 올라가 흡입구(반경 39 mm) 바깥으로 돌린 뒤, 아비오닉스 선반의 배선 슬롯 2개(ESC 브래킷 바깥, 만능기판 밑)로 올린다. 흡입구 위를 가로지르면 선이 팬에 빨려 들어간다.
- 배선 슬롯은 10/16에 옮겼다(x 62-74, |y| 8-18). 예전 위치는 ESC 브래킷 플랜지에 절반 넘게 가려졌고, 첫 수정 위치는 만능기판 인서트 보스를 잘랐다(#59). 지금은 `hopper_params.scad` 검증 echo가 세 가지 간격을 모두 확인한다.
- 이 경로의 서보선 길이는 렌더 경로로 어림한 값이 약 290 mm(180°·270° 서보)와 약 370 mm(0°·90° 서보)다. MG90S 기본 리드(250 mm, TowerPro 공식)로는 모자라므로 서보 연장선 4개(150-200 mm)가 필요하다.

## 질량 특성 (`cad/cg/`)

`python cad/cg/cg_estimate.py`는 `cad/cg/parts.csv`의 부품별 질량·모양·위치로 총질량, 무게중심(x, y, z), 토크 팔, 관성 모멘트, 민감도를 낸다. 질량 출처는 행마다 적었다(공식 사양, 리스팅, 출력물 질량의 하한 가정, 실측, ESTIMATE). 실물을 저울로 재면 그 행을 바꾼다.

과거 2026-10-16 계산(850 mAh 가정, 현재 기준 아님): 746 g, CG (+0.4, +1.6, 67.6) mm, l 103.6 mm, Jxx 0.0079 / Jyy 0.0070 / Jzz 0.0028 kg·m². 1300 mAh(156 g)를 쓰면 CG가 배터리 쪽으로 5.3 mm 치우친다. 베인 한계(약 6.5 mm 상당) 안이지만 Stage 1 PD가 기울기 5.6°를 남겨 합격 기준(5°)을 넘는다. 이는 당시 배치와 질량 가정의 결과다. 현재 CAD와 `parts.csv`는 실측한 4S 1300 mAh, 159.5 g을 반영한다. 배터리 최종 선택·실제 출력물 질량·트림량은 아직 확정하지 않았다(#219, #26).

## 조립 간섭 전수 검사 (`cad/tools/check_interference.py`, #59)

프린트 부품 9종과 구매품 외형 14종(EDF, 기둥, 다리, 스파, 서보, 배터리, ESC, 만능기판, 수신기, Teensy, IMU, UBEC, 베일, 무게추)을 조립 위치에 놓고 모든 쌍의 겹친 부피를 계산한다. 베인은 중립과 하드스톱(±`vane_stop_deg`) 상태를 따로 본다. 겹침이 0.001 cm³를 넘으면 실패한다(약 15분).

```bash
python cad/tools/check_interference.py
```

과거 2026-10-17 형상 결과: 쌍 198개, 정밀 검사 30쌍, **간섭 없음**. 현재 형상은 아래 재검사를 따르며 이 과거 결과로 제작을 승인하지 않는다. 이 검사로 찾아 고친 것: 발 범퍼에 다리 소켓 없음, 다리(수직에서 54°)가 수직 소켓에 안 들어감 → 링 바깥 보스와 기울인 소켓, 베인 꺾기 함수가 피벗이 아니라 원점 기준, ESC 모형 위치. 같은 검토에서 베일이 흡기 구멍 안쪽에 떨어지던 것도 고쳤다(반경 51 mm, 상판 구멍 2개).

이 검사가 보지 않는 것: 실물 치수(구매품은 공식·리스팅 외형), 조립 순서와 공구 접근, 출력 가능성(서포트·벽 두께), 강도, 배선 굽힘.

## 10/19 리뷰 반영과 제작 조건

- 무게추 후보는 강철 밀도 7.85를 가정한 고리 2개(D18, ID5.5, 높이 약 19.88 mm)다. 구멍을 뺀 합계 72 g이 질량표·간섭 형상에서 같다. 구매·실측 완료가 아니며 실제 트림량은 슬라이서 질량과 조립 후 측정으로 다시 정한다.
- 가까운 서보 홀은 축에서 9.0-10.5 mm만 지원한다. 혼 통과 구멍 D10.5와 외경 5 mm 이하 와셔 사이의 지지면 폭을 검사한다. 기존 2.5 mm부터의 슬롯은 혼 구멍과 합쳐져 폐기했다. 혼 단면이 9 x 2.2 mm 가정과 맞는지 실제로 대조해야 한다.
- 출력물 질량표는 인필만 계산한 LOWER_BOUND 시나리오다. print_mass.py는 100 % 실체 값까지 범위를 표시한다. 실제 출력물 질량, 전체 CG·TWR, 발주 승인은 확정하지 않았다.

### 면 접촉 판정 (#220)

교집합을 이루는 연결 조각마다 모든 꼭짓점의 x/y/z 중 하나가 정확히 일정하면, 두께 없는 축 정렬 면·선 접촉으로 기록한다. 부피 합이 0이라는 이유만으로 통과시키지 않는다. 면 접촉과 실제 부피가 섞였거나 기울어진 퇴화 면은 자동 통과시키지 않는다. 입력 부품은 먼저 오류·경고 없는 닫힌 실체인지 확인한다. 알려진 비다양체 경고만 이 접촉 분류에서 허용하며, 알 수 없는 모듈·렌더 오류는 실패한다. 실제 조립 치수·볼트 지지면·강도는 이 계산과 별개다.

`--out <새 폴더>`를 붙이면 각 SCAD/STL/렌더 로그를 보존한다. 경계 상자는 0.01 mm 이하의 겹침도 정밀 검사로 넘긴다. 실제 부피 판정 허용값은 기존 0.001 cm3다.

빈 STL만으로 접촉이라고 판정하지 않는다. 정상 종료인데 STL 삼각형이 없으면 OFF 형식을 추가로 내보내 모든 연결 조각의 평면성을 확인한다. OFF도 비었거나 오류·알 수 없는 경고·실제 두께가 있으면 실패한다. 베인 양끝은 중립 베인을 제외한 모든 고정 부품과 비교한다.

### 전자부 배치 후보 (#222)

수신기·Teensy·IMU의 위치와 UBEC 반경은 `hopper_params.scad`의 전자부 변수로 정한다. 수신기는 FS-iA6B 제조사 페이지의 26.2×47×15 mm·10 g 공칭값을 사용하며, 구매품 일치와 실제 질량은 확인 필요다. 수신기를 기판 바깥쪽으로, Teensy·IMU를 안쪽으로 나누고 UBEC 바깥면과 무게추 사이에 1.5 mm 설계 간격을 뒀다. 과거 질량표의 위치와 6 g 예산값은 현재 계산에 쓰지 않는다. 실제 절연·고정·연결부 여유는 #219에서 확인한다.

### 슬라이서 질량 시나리오 (#223)

`cad/tools/slice_reference.py`와 `cad/slicing/reference-0.4mm.ini`는 PrusaSlicer 2.9.6에서 외벽·상하면을 포함해 질량을 계산한다. 실행 방법과 결과, 경고는 [10/20 보고서](reports/2026-10-20/README.md)에 있다. 원본 `parts.csv`를 덮지 않고 독립 `parts-reference.csv`를 만든다. 외주 프로파일이나 실측값이 아니며 생성한 G-code를 출력에 쓰지 않는다.
