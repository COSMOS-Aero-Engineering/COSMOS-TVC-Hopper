# Stage 2 자유비행 착륙 시뮬레이션

단일 EDF와 베인 4개를 단 강체를 공중에서 놓고 평면 위에 착륙시킨다. PD와 PPO는 같은 환경에서 같은 다섯 명령을 낸다. 시드는 초기 자세와 위치를 정한다. 실물 운용이나 구속 시험대의 Stage 1 성능을 판정하는 데 이 결과를 쓰지 않는다.

## 실행

저장소 루트에서 실행한다. MuJoCo는 `stage2` 선택 의존성이다. 학습 예제의 4,096스텝은 체크포인트 저장과 재평가를 시험할 때 쓰는 예산이다. PPO는 256스텝 단위로 학습한다.

```powershell
python tasks.py stage2
uv run --locked --package cosmos-sim --extra stage2 python -m sim.stage2 evaluate --policy pd --episodes 12 --seed 0 --out runs/stage2/pd
python ship.py capped 8G -- uv run --locked --package cosmos-sim --extra stage2 python -m sim.stage2 train --seed 41 --steps 4096 --model runs/stage2/ppo.zip
uv run --locked --package cosmos-sim --extra stage2 python -m sim.stage2 evaluate --policy ppo --model runs/stage2/ppo.zip --episodes 12 --seed 0 --out runs/stage2/ppo
```

평가는 한 줄에 에피소드 하나씩 JSON을 출력한다. `outcome`은 종료 원인, `impact_m_s`는 패드가 처음 닿거나 다시 닿을 때 기록한 하강 속도의 최댓값이다. CSV 파일 이름에는 정책과 시드가 들어간다. 같은 출력 폴더에서 같은 정책과 시드를 다시 실행하면 CSV를 덮어쓴다.

웹 뷰어에서 **CSV 열기**로 파일을 골라 **재생**을 누른다. `source=SIM`, `mode=PID`(기준 PD) 또는 `RL`(PPO)이다. 웹은 자세와 서보 명령을 재생한다. `px,py,pz`와 `vx,vy,vz`는 세계 좌표의 CG 위치(m)와 속도(m/s)로 분석용 열이다. 현 뷰어는 이 열로 기체를 이동시키지 않는다. 각 행은 제어 전 상태, 해당 명령과 보상을 담는다. 마지막 행은 종료 상태만 담는다.

## 강체와 힘

[CAD 부품표](../../cad/cg/parts.csv)와 [질량 계산기](../../cad/cg/cg_estimate.py)의 점 질량을 읽는다. 배기면이 CAD 원점이며 +X는 전방, +Y는 왼쪽, +Z는 위다. MuJoCo의 강체 원점을 CG에 두고 CAD의 모든 힘 작용점과 충돌 형상에서 CG를 뺀다. 비대각 성분까지 계산한 CG 기준 관성 텐서를 넘긴다. [설계 03 §2·§4](../../docs/design/03-control-pipeline-design.md)

PyFlyt의 양력면은 링크의 속도에서 바람을 뺀다. 기본 모델에는 정지 호버 중에도 베인에 작용하는 제트 속도가 없다. PyFlyt 0.29는 NumPy <2를 요구하고 저장소는 2.5.3을 고정한다. 여기서는 헤드리스 MuJoCo가 6자유도 운동과 충돌을 적분하고 자체 제트 모델이 외력을 공급한다. [저장소 조사 §3](../../docs/design/rl-open-source-survey.md) · [PyFlyt 소스](https://github.com/jjshoots/PyFlyt/blob/master/PyFlyt/core/abstractions/lifting_surfaces.py) · [배포 의존성](https://pypi.org/pypi/PyFlyt/0.29.0/json) · [MuJoCo 관성 정의](https://mujoco.readthedocs.io/en/stable/XMLreference.html#body-inertial)

EDF 추력 T를 원주 방향으로 4등분한다. 한 베인의 측력은 `T × CLalpha × A_fin / (2 × A_duct) × angle_rad`이다. 절댓값의 상한은 `(T/4) × sin(10°)`다. 각 구간의 축력은 `sqrt((T/4)² − 측력²)`이다. 작용점마다 힘과 CG 기준 모멘트 `r × F`를 합산한 뒤 세계 좌표로 회전한다. 양의 명령에서 1·3번 측력은 +Y, 2·4번은 +X다. 서보의 실물 장착 부호는 별도 보정 대상이다.

## 관측과 착륙 판정

정책은 세계 좌표 위치·속도 6개, 기체에서 세계로 회전하는 쿼터니언(wxyz) 4개, 기체 각속도(rad/s) 3개, 현재 베인각(rad) 4개, EDF 속도 비율 1개를 받는다. 설계 03에 열거한 값은 17개다. 여기에 지연된 EDF 상태를 더해 총 18개다. 행동은 FWD/LEFT/AFT/RIGHT 베인 명령과 스로틀이다. 각 행동 범위는 −1에서 +1이고 스로틀만 0에서 1로 환산한다.

물리 적분은 4 ms마다 하고 제어는 20 ms마다 한다. 초기 발 높이는 수평 자세 기준 0.45–0.65 m, CG의 수평 위치는 축마다 ±0.05 m, 초기 자세각은 축마다 ±0.055 rad 범위에서 뽑는다. 초기 속도는 0이며 EDF 초기 회전 비율은 수평 호버 추력에 맞춘다. PD는 수평 위치와 속도로 목표 기울기를 정하고 하강 속도와 자세 오차를 추력·토크로 환산한다. 착지 높이 3 mm 안에서 스로틀을 끈다.

- 패드가 새로 닿을 때 패드 중심의 하강 속도가 0.45 m/s 또는 수평 속도가 0.40 m/s를 넘으면 강한 접촉으로 종료한다.
- 패드 3개 이상이 닿고 EDF 속도 비율이 0.10 이하인 상태에서 착륙을 판정한다. 수평거리 0.20 m 미만, 기울기 8° 미만, 속력 0.10 m/s 미만, 각속력 0.25 rad/s 미만을 포함한 모든 조건이 연속 0.15 s 유지돼야 한다.
- 하우징 접촉, 45° 초과 기울기, 수평거리 1.5 m 또는 CG 높이 2.5 m 초과는 실패로 종료한다. 8 s가 지나면 시간 제한으로 중단한다.
- 매 제어 스텝에 경과 시간, 남은 높이, 수평 오차, 기울기와 속도에 비용을 준다. 착륙 보상은 +10, 실패는 −10, 시간 초과는 −5다. 모든 문턱은 이 시나리오의 비교 조건이다.

## 검증 범위

`python tasks.py check`에는 CG·관성 변환, 네 베인의 측력과 요 부호, 무추력 자유낙하, 기울어진 기체의 병진 가속도, 시드 재현, 연착륙·강한 접촉·시간 초과와 CSV 검사도 들어 있다. PD와 PPO는 같은 초기 시드를 사용할 수 있다. 시드는 기체 물성치를 바꾸지 않는다.

실측 전 항목은 실험 A(#244), 조립 질량·CG·관성(#261, #262), 베인 치수·제트 단면·복원 모멘트(#265, #118, #263), 서보와 EDF 응답(#202, #264), 접촉 모델(#295)이다. 공기 저항·돌풍, 회전자 반작용과 자이로(#119), 지면 효과, 배터리 전압 강하, 구조 변형과 센서 오차는 모델에 없다. 초기 위치와 속도, 베인각은 시뮬레이터의 참값이다. 실기 탑재에는 별도 관측기와 구속 시험이 필요하다.
