# PPO 스로틀 0 수렴 원인 분석 (#90)

## 결론

현재 PPO는 위치가 구속된 Stage 1 환경에서 스로틀을 꺼 모든 토크를 없애는 정책으로 수렴했다. 이 정책의 낮은 스로틀이 나쁜 평가 결과를 만드는 것은 교차 실험으로 확인했다. 보상식이 PPO를 이 정책으로 수렴시킨 학습 원인인지는 아직 비교 실험이 필요하다. 스로틀을 끄는 동안 베인 제어도 배우지 못했다.

## 왜 리턴이 -32 근처인가

초기 자세 세 축은 각각 `U(-0.3, 0.3)` rad다. 스로틀 0이면 추력, 베인 토크, 횡 무게중심 토크가 모두 0이고 초기 각속도도 0이라 자세가 멈춘다. 이때 스텝당 기대 자세 비용은 다음과 같다.

```text
E[phi^2 + theta^2 + 0.1 psi^2]
= 0.3^2/3 + 0.3^2/3 + 0.1 * 0.3^2/3
= 0.063
```

스로틀 정규화 행동 `-1`의 행동 비용 `0.001`을 더해 500스텝을 계산하면 기대 리턴은 `-32.00`이다. 실제 200-seed PPO 리턴은 `-33.14`다.

## 기존 모델 교차 실험

명령:

```powershell
python ship.py capped 8G -- uv run --frozen --project . python sim/sim_stage1/ppo_diagnosis.py --model sim/sim_stage1/hopper_attitude_ppo.zip
```

평가 seed 0-199, 도메인 랜덤화 켬:

| 정책 | 평균 리턴 | 평균 길이 | 넘어짐 | 최종 기울기 중앙값 |
|---|---:|---:|---:|---:|
| PD | -4.82 | 500.0 | 0.0% | 2.5도 |
| PPO | -33.14 | 499.4 | 0.5% | 13.8도 |
| PPO 베인 + 스로틀 100% | -32.53 | 75.4 | 100.0% | 66.0도 |
| PD 베인 + PPO 스로틀 | -32.42 | 500.0 | 0.0% | 13.5도 |

PPO의 실제 스로틀은 평균 `0.0054`, 최댓값 `0.4100`이며 전체 스텝의 90.4%가 0이었다.

- PD 베인에 PPO 스로틀을 붙이면 초기 자세가 남는다. PPO 스로틀만으로 실패를 재현할 수 있다.
- PPO 베인에 100% 스로틀을 붙이면 모든 seed가 넘어진다. 기존 정책의 베인 출력은 복원 제어를 배우지 못했다.

## 평가 방식

20개 seed의 추가 진단에서 deterministic PPO와 stochastic PPO의 최종 기울기 중앙값은 모두 `12.9도`였다. 평균 리턴은 각각 `-28.41`, `-28.90`이었다. 평가의 deterministic 설정은 주원인이 아니다.

## 고정 스로틀 진단 학습

`FixedThrottleEnv`는 PPO 행동에서 스로틀을 빼고 베인 4개만 학습하며 환경에는 스로틀 100%를 보낸다. 학습 seed는 기존과 같은 10000이다.

| 학습량 | 에피소드 | 처음 20개 평균 리턴 | 마지막 20개 평균 리턴 | 처음·마지막 평균 길이 | 평가 seed | 결과 |
|---:|---:|---:|---:|---:|---:|---|
| 2,048 | 29 | -27.13 | -28.90 | 확인하지 않음 | 0-19 | 넘어짐 100%, 기울기 70.8도 |
| 20,000 | 263 | -27.13 | -29.58 | 66.7·68.6 step | 0-19 | 넘어짐 100%, 기울기 70.0도 |

음수 보상을 합산하므로 리턴은 조기 종료 길이에 영향을 받는다. 따라서 처음과 마지막 에피소드의 리턴만으로 학습 개선을 판정하지 않는다. 20k 뒤의 고정 평가에서는 20개 seed가 모두 넘어져 독립 베인 4개의 복원 제어를 확인하지 못했다. 200k와 1M, 3축 믹서 행동, 관측 정규화, 종료 비용은 후속 이슈에서 같은 평가 seed 0-199로 비교한다.

## 이슈의 가설 판정

| 가설 | 결과 | 판정 |
|---|---|---|
| 학습량 부족 | 기존 200k 정책이 스로틀 0 정책에 수렴했다. 고정 스로틀 20k도 개선되지 않았다 | 판정 못함. 1M은 후속 실험 |
| 관측 크기가 제각각 | 스로틀 관측을 추가한 7차원 모델도 같은 정책에 수렴했다. `VecNormalize` 실험은 아직 안 했다 | 원인 여부 미확인. 후속 실험 |
| 평가 방식 | 20-seed deterministic 12.9도, stochastic 12.9도 | 원인 아님 |
| 보상 식 | 스로틀 0 기대 리턴 -32.00과 실제 -33.14가 가깝다. 교차 실험은 낮은 스로틀이 성능 실패를 만드는 것을 확인했지만 학습 인과는 확인하지 않았다 | 강한 가설. 후속 비교 실험 필요 |
| 하이퍼파라미터 | SB3 기본값에서 스로틀 0 정책이 나왔다. RL Zoo 설정 실험은 아직 안 했다 | 원인 여부 미확인. 후속 실험 |

## 근거와 한계
